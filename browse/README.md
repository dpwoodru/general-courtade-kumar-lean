# browse/ — read-only copies of the readable proof code

These are **byte-identical copies** of 1359 of the 45,500 source files (238,690 lines), for reading on GitHub. **The build does not use this folder**: `BUILD/build_plain.sh` compiles the complete source tree extracted from the release asset `sources_v3.tar.zst` into `sources/`. Every copy here has the sha256 recorded for it in `SOURCES_MANIFEST.tsv`.

## Selection rule

- always included: `GeneralCK.Statement` and every `CKRoute.*` module (the proof skeleton);
- otherwise, a module is included unless it looks like generated certificate data:
  - its last name component contains a number with two or more digits (numbered cells, shards, leaves);
  - or its name contains `Generated`, `Data` or `Coverage`;
  - or the file has more than 3,000 lines.

Start with [`GeneralCK/Statement.lean`](GeneralCK/Statement.lean) (the statement) and [`CKRoute/Final.lean`](CKRoute/Final.lean) (the final theorem); `REVIEW_GUIDE.md` in the repository root explains the proof skeleton and the certificate families.
